# `@inhuman.tools/policy-continue`

No pre-tool door was found for Continue. This package exports `evaluateCall` so a wrapper can call it. The function cannot be installed as a Continue plugin or hook today.

`evaluateCall` uses `defaultPolicy`. Bash strings use `bash`. Path writes use `write`. Floor `block` denies without the judge. Floor `approve` allows. Floor `ask` and `deny` call `judge`. A null judge, a null vote, and a thrown judge deny.

`judgeWith` binds a decide capability. `@inhuman.tools/policy-continue-sage` and `@inhuman.tools/policy-continue-jev` import it. This package judges with structured output.
