# Inhuman for iPhone

Native projects, sessions, composer, and approvals. The transcript and the workflow dialog stay the web page, loaded in the session screen.

The Simulator reaches the daemon through `harness web` on this Mac (`http://127.0.0.1:8787`). A phone on the network cannot; the daemon listens on loopback.

```sh
pnpm --filter @inhuman.tools/harness-ios-app ios
```

The composer sits in the screen and follows the keyboard. Liquid Glass stays on the system navigation bar. The app does not paint its own glass.
